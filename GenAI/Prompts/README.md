## Prompts
- Static Prompt: A prompt with fixed instructions and content that remain the same for every request.
- Dynamic Prompt: A prompt whose content changes based on variables, user input, or other runtime data.

## PromptTemplate
Instead of hardcoding prompts, PromptTemplate allows you to define placeholders that can be filled in at runtime with different inputs.

### Why use PromptTemplates?
- Default validation
- Reusable
- LangChain Ecosystem support

## Messages
- SystemMessage: Defines the model’s role, behavior, and instructions.
- HumanMessage: Contains the user's input or question.
- AIMessage: Contains the response generated by the model.
- ToolMessage: Contains the output returned by a tool called by the model.

### ChatPromptTemplate
It is used to create a structured chat prompt containing messages with different roles, such as system, human, and AI. It supports placeholders that can be filled dynamically with input values when the prompt is formatted.

### MessagesPlaceholder
It is a special placeholder used inside a ChatPromptTemplate to dynamically insert chat history or a list of messages at runtime.
